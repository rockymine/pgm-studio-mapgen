# Sandscar — simplified DTM

One large rectangle per team + small spawn attached at the back.

## Geometry (cell = 5 → blocks)

| Element | Detail |
|---------|--------|
| Team plateau | single piece `[-12,4] → 24×18 cells` (120×90 blocks) |
| Spawn | small pad attached at back centre |
| Same-team monuments | 10 cells apart = **50 blocks** |
| Enemy mirror distance | ~100 blocks centre-to-centre |
| Mid | pure **build region** (no solid pieces) |

## Relief
- Depression under the **west** monument
- Hill under the **east** monument
- Gentle rise toward spawn, flatter front approaches

## Props
- Paths: spawn → west monument, spawn → east monument, spawn → front
- **Meandering river** running east–west across each team half (water path prop)
- Spawn hall + two monument shelters
- Acacia trees

## Theme
Sandstone + endstone + birch + brick roofs (unchanged from previous styles).
