# The maps-changelog channel, 2026

**What is here.** `maps-changelog-2026.csv` holds every message of the Overcast Community Discord's `#maps-changelog`
channel from 31 December 2025 to 27 November 2026: 1,578 messages, read on 27 November 2026 in the author's
signed-in browser by stepping through the channel in time order. The channel is the GitHub feed of the map
repositories: commits to CommunityMaps (491), PublicMaps (235), MapPools (105) and PrivateMaps (83), and pull-request
events (about 660).

**Why it matters.** PrivateMaps is a private repository that no clone in this research can read, so this feed is
the only record here of what was uploaded to it; research `15` §3 lists RuedigerLP's commits of the test weeks.

**Columns.** `posted_utc`, `discord_msg` (the message id in the channel), `text` (the message as displayed, the
GitHub embed flattened to one line) and `links` (the commit, compare or pull-request links in it).
